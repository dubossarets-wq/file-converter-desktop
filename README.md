# Конвертер файлов (File Converter)

Настольное приложение для Windows: сжатие и конвертация изображений, видео,
аудио, документов и PDF. Всё обрабатывается локально, файлы никуда не
отправляются.

## Возможности

**Изображения** — WebP, JPEG, PNG, AVIF, GIF, BMP. Умное сжатие под заданный
вес, изменение размера (по ширине/высоте или по короткой/длинной стороне),
выбор алгоритма ресемплинга, ограничение палитры, режим «до/после» с
попиксельным сравнением.

**Видео** — MP4, WebM, MKV, AVI, MOV. Аппаратное ускорение NVENC с откатом на
CPU, режим без перекодирования (ремультиплексирование), обрезка по времени,
извлечение звука в MP3, превью кадром из середины ролика.

**Аудио** — MP3, AAC, OGG, WAV, FLAC. Обрезка тишины, нормализация громкости
по EBU R128.

**Документы** — DOCX, ODT, RTF, Markdown, HTML (через pandoc).

**PDF** — сжатие с пресетами качества, настройкой DPI и качества встроенных
изображений, удалением метаданных, скрытых данных и JavaScript, оптимизацией
шрифтов и подготовкой для быстрой загрузки в интернете (линеаризация).
Показывает число страниц и изображений, оценивает результат до запуска.

**Общее** — пакетная обработка, рекурсивное перетаскивание папок, папка
сохранения по умолчанию, суффикс к именам файлов, запоминание настроек между
запусками.

## Стек

Electron 32. Рендерер — один `index.html` без сборщика и фреймворков. Главный
процесс (`main.js`) вызывает внешние бинарники и отдаёт результат по пути на
диске, а не буфером через IPC — иначе многогигабайтные файлы роняют
структурированное клонирование Electron.

| Задача | Чем делается |
|---|---|
| Изображения | Canvas в рендерере, собственные ядра ресемплинга (Lanczos / билинейное) |
| GIF | ffmpeg, двухпроходная палитра |
| Видео и аудио | ffmpeg |
| Документы | pandoc |
| PDF | Ghostscript (сжатие) + pdf-lib (разбор, метаданные, определение пароля) |

## Сборка из исходников

Бинарники третьих сторон в репозиторий не попадают: вместе они весят около
360 МБ, а `pandoc.exe` (221 МБ) вообще превышает лимит GitHub в 100 МБ на файл.
Их нужно положить самому:

```
resources/
  ffmpeg/ffmpeg.exe           https://www.gyan.dev/ffmpeg/builds/ (essentials)
  pandoc/pandoc.exe           https://github.com/jgm/pandoc/releases
  ghostscript/                https://github.com/ArtifexSoftware/ghostpdl-downloads/releases
    bin/gswin64c.exe            (инсталлятор распаковывается 7-Zip без запуска;
    bin/gsdll64.dll              нужны только bin, lib, Resource, iccprofiles)
    lib/  Resource/  iccprofiles/
```

Дальше:

```bash
npm install
npm start                # запуск в режиме разработки
npm run dist             # сборка папки dist/win-unpacked
npm run dist:nsis        # установщик из уже собранной папки
```

Иконка применяется отдельным шагом через `rcedit` между `dist` и `dist:nsis`:
electron-builder собирается с `signAndEditExecutable: false` (иначе он тянет
winCodeSign, который не распаковывается на Windows без прав администратора), а
вместе с этим пропускает и собственный шаг с иконкой.

## Лицензии зависимостей

Ghostscript распространяется под AGPL, ffmpeg — под LGPL/GPL в зависимости от
сборки, pandoc — под GPL. Для личного использования это ни на что не влияет, но
при публичном распространении сборки условия этих лицензий применяются к ней.
